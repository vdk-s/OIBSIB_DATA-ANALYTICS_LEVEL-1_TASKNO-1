# OIBSIB_DATA-ANALYTICS_LEVEL-1_TASKNO-1
📊 Exploratory Data Analysis (EDA) on Retail Sales Data
McDonald's Menu Dataset
📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a retail sales dataset derived from the McDonald’s menu. The objective is to analyze nutritional and product-related attributes to uncover patterns, trends, and insights that can help in understanding product offerings and making data-driven business or health-related decisions.
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
📂 Dataset Description

Source: Kaggle (McDonald’s Menu Dataset)

Format: Excel / CSV

Records: 260 menu items

Features: 24 columns including:

Item name

Category

Calories

Fat, Carbohydrates, Protein

Cholesterol, Sodium

Vitamins and minerals (% Daily Value)
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
🎯 Objectives

Understand the structure and quality of the dataset

Perform descriptive statistical analysis

Analyze calorie distribution across categories

Identify high-calorie and low-calorie items

Visualize insights using plots

Provide actionable recommendations based on findings
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
🛠 Tools & Libraries Used

Python

Pandas – Data loading and manipulation

NumPy – Numerical computations

Matplotlib – Data visualization

🔍 Steps Performed
1️⃣ Data Loading

Loaded the dataset using Pandas

Verified dataset shape and column names

2️⃣ Data Cleaning

Checked for missing values

Verified data types

Dataset found to be clean with no null values

3️⃣ Descriptive Statistics

Calculated mean, median, standard deviation

Analyzed distributions of calories, fat, sugar, and sodium

4️⃣ Product & Category Analysis

Average calories by category

Identified highest and lowest calorie items

Compared nutritional values across product categories

5️⃣ Visualization

Bar charts for average calories per category

Sorted tables for extreme values

Simple visual insights for better interpretation
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
📈 Key Insights

Chicken & Fish and Smoothies & Shakes categories have the highest average calories

Some items contain extremely high sodium and fat values

Beverages and coffee items generally have lower calorie counts

A small number of items contribute to extremely high nutritional values (outliers)
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
💡 Recommendations

Promote lower-calorie and low-sodium items for health-conscious customers

Highlight nutritional transparency for high-calorie products

Use category-wise insights to redesign menu combinations

Assist customers in making informed dietary choices
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
✅ Conclusion

The EDA successfully uncovered meaningful patterns and trends in McDonald’s retail menu data. The analysis demonstrates how exploratory data analysis can support business insights, nutritional awareness, and strategic decision-making in the retail food industry.
